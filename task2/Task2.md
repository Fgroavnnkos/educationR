# Задание 1. Students

Создать консольное приложение **"Students"**.
## Требования к классу Student

1. Создать класс `Student` со свойствами:
   - `val fullName: String`
   - `val email: String
1. Реализовать конструктор, принимающий `email: String`.  
   На основании email восстановить имя и фамилию и сформировать `fullName`.
2. Реализовать конструктор, принимающий `name: String` и `surname: String`.  
   На основании имени и фамилии сформировать `fullName` и email в формате  
   `name.surname@gmail.com` (в нижнем регистре).
3. Переопределить `equals()` и `hashCode()` так, чтобы два студента считались равными, если совпадает их email.

## Логика в main()

5. Создать массив `subjects` из 6 школьных предметов.
6. Создать трёх студентов с использованием конструктора, принимающего email.
7. Создать трёх студентов с теми же именами и фамилиями, используя конструктор `(name, surname)`.

8. Создать словарь:

```kotlin
val studentSubjectDict = mutableMapOf<Student, MutableSet<String>>()
```

9. Для всех шести студентов заполнить словарь тремя случайными предметами из `subjects`
10. Проверить, что в словаре содержится ровно 3 уникальных ключа.

# Юнит-тесты к заданию Students

## Требования к тестам (JUnit 5)

1. Тест `equals()` и `hashCode()`:  
Проверить, что два студента с одинаковым email считаются равными и имеют одинаковый hashCode.
2. Тест работы словаря:  
Проверить, что при записи данных шести студентов размер словаря равен 3.

# Задание 2. Performance

Создать консольное приложение **"Performance"**.
## Требования

1. Создать класс `C` с одним полем `i: Int`.
2. Создать data class `S` с одним полем `i: Int`.
3. В `main()`:
	- создать и инициализировать `IntArray` из 100 000 элементов случайными значениями;
	- создать и инициализировать `Array<C>` из 100 000 элементов;
	- создать и инициализировать `Array<S>` из 100 000 элементов.
4. Перед созданием каждого массива и после его создания измерять используемую память с помощью:
```kotlin
Runtime.getRuntime().totalMemory() - Runtime.getRuntime().freeMemory()
```
Вывести разницу для каждого массива.

5. Выполнить сортировку:
	- `primitiveArray.sort()`
	- `classArray.sortBy { it.i }`
	- `dataClassArray.sortBy { it.i }`
6. Измерить и вывести время выполнения каждой сортировки.
